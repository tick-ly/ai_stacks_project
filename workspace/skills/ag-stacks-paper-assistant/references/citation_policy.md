# Citation Policy

## Citation Types

- Stacks source citations: `[S1]`, `[S2]`, ...
- Paper citations: `[P1]`, `[P2]`, ...

## Minimum Citation Requirements

- Every theorem-level factual statement should have at least one citation.
- Every nontrivial definition should have a source citation if retrieved.
- Research trend claims should cite papers.

## Stacks Citation Format

Use:

- tag
- reference number if available
- title if available
- URL: `https://stacks.math.columbia.edu/tag/<TAG>`

Example:

- `[S1] Tag 01UA, Lemma 37.12.1, https://stacks.math.columbia.edu/tag/01UA`

## Paper Citation Format

Use:

- title
- authors (if available)
- year (if available)
- venue or source (if available)
- URL

Example:

- `[P1] Some Paper Title, A. Author, 2022, arXiv:xxxx.xxxxx, https://arxiv.org/abs/xxxx.xxxxx`

## Ranking Citation Preference

1. Stacks citations for foundational AG facts.
2. Paper citations for latest methods/results.
3. If no high-quality source is found, state insufficiency explicitly.
