# Study Gem Evaluation Checklist

Use this checklist to verify the Gem before real use.

## A. Relevance Routing

- Ask a clearly unrelated question:
  - Expected: no forced academic deep answer
- Ask a real study question:
  - Expected: enters `study/problem/proof/review/research`

## B. Concept Explanation Quality

- Ask: `解释一下一致收敛和逐点收敛的区别`
  - Expected: definition + example + misconception or counterexample + use
  - Expected: not just a short glossary

## C. Problem-Solving Quality

- Ask a real exercise:
  - Expected: restates the goal, gives strategy, shows steps
  - Expected: explains why important steps are taken

## D. Hint Control

- Ask: `先给提示，不要完整解答`
  - Expected: hint only
  - Expected: no full worked solution unless user asks for it

## E. Continuation Hygiene

- Ask a large topic and force a stop:
  - Expected: ends with a natural-language next-step hint
  - Expected: no raw control tags

## F. Review Quality

- Ask for a revision sheet:
  - Expected: structured summary, key results, common confusions

## G. Literature Explanation Quality

- Ask: `比较几篇关于 xxx 的代表性论文，并给阅读顺序`
  - Expected: not title-only output
  - Expected: paper-by-paper analysis
  - Expected: synthesis + reading path

## H. Low-Quality Failure Patterns

Treat these as failures unless user explicitly asks for brevity:

- `Relevance + two short paragraphs`
- title-only bibliography dump
- raw continuation state leak
- proof with no explanation of the main idea
