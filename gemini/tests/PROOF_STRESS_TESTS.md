# Proof 高压测试

本组重点压测：

- 是否会先澄清正确命题，再进入证明
- 是否把关键假设讲清楚
- 是否能把定义、局部化、Tor、cotangent complex 这类工具接成一条可核查的证明链
- 是否会把“证明思路”伪装成“完整证明”

## P1. 局部平坦判据压力题

**Prompt**

```text
请给出一个可核查的讲解，说明如何在点 x 上判断一个有限表示模的平坦性。更具体地说：
设 A -> B，M 是一个有限表示的 B-模，x 对应于 B 的素理想 q，p 是它在 A 中的像。
请先明确写出你要使用的“局部平坦判据”的正确版本，再解释 Tor_1、纤维、局部化分别扮演什么角色，并给出证明路线。
要求：
1. 如果你的判据需要额外假设，必须先说明。
2. 不要只给结论，要指出哪些步骤是定义，哪些步骤是引用定理，哪些地方最容易漏条件。
3. 最后说明：如果去掉有限表示或把点态判断误当成全局判断，会出现什么风险。
```

**通过信号**

- 先校正命题版本，而不是直接把一个模糊判据硬说成标准定理。
- 明确指出哪些条件是定理版本自带的，哪些只是为了教学组织。
- 会区分“在点处平坦”“在邻域内平坦”“全局平坦”。
- 不把 `Tor_1 = 0` 单独说成在所有场景下都足够。
- 能指出有限表示在某些局部到邻域的结论里为什么关键。

**失败信号**

- 把不同版本的局部平坦判据混成一条。
- 只给含糊路线，没有解释 Tor 或纤维到底在检查什么。
- 把点态结论直接升级成全局结论。
- 不提任何可能漏掉的假设。

**续写检查**

```text
继续，把你刚才省略掉的关键一步补成更细的证明说明，尤其解释为什么这里只能得到点附近的结论而不是自动全局化。
```

## P2. 基变换下平坦性稳定

**Prompt**

```text
请证明并讲清楚：平坦态射在基变换下稳定。
要求你分两层来讲：
1. 先在仿射情形把命题翻译成环与张量积的语言，并说明 exactness 为什么被保留。
2. 再回到 scheme 语言解释这件事为何是局部命题。
之后请补一个边界讨论：如果把“平坦”换成“纤维 reduced”或“纤维 normal”，为什么类似命题就不能这样直接说。
不要只给一句“因为 flatness 对张量好”，要把逻辑链条写出来。
```

**通过信号**

- 会把 proof 分成 affine/ring 层和 scheme/local 层。
- 真正解释“张量保正合”与 base change 的关系，而不是空泛引用。
- 边界讨论里能明确指出 reduced/normal 一类性质需要更强条件，至少举出一个典型失效方向。

**失败信号**

- 只说“平坦性局部可检验，所以结论成立”，却没给张量 exactness 的骨架。
- 把“纤维 reduced/normal”说成自动稳定而不给附加条件。
- 边界部分没有任何具体失效机制。

## P3. 用 cotangent complex 解释 étale

**Prompt**

```text
请用 cotangent complex 的语言解释为什么 étale morphism 可以看作“既 flat 又无穷小上不产生新变形”的态射。
要求：
1. 先给一个兼容经典定义的正确表述，说明 L_{X/S} ≃ 0 与 unramified / flat / étale 的关系。
2. 不要只背诵“étale 等价于 cotangent complex 为零”；请说明这和经典 Jacobian 判据、无穷小提升性质分别怎么联系。
3. 指出逆向叙述需要哪些有限表示或有限呈示条件，不能偷换。
4. 最后给一个容易混淆但不成立的近似命题，提醒边界。
```

**通过信号**

- 能把 `L_{X/S}` 的消失与 classical étale theory 对上。
- 会指出“零 cotangent complex推出 étale”需要有限表示或类似有限性条件。
- 能区分 unramified、smooth、étale 的关系，而不是全混在一起。
- 边界提醒具体，不空泛。

**失败信号**

- 把 `L_{X/S} ≃ 0` 在任何环境下都说成等价于 étale。
- 完全不提有限表示/有限呈示。
- 只给术语堆叠，没有讲 classical 与 derived/viewpoint 的桥。
